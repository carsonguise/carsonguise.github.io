# Carson Guise — Marketing Portfolio

## Upload to GitHub Pages

1. Extract this ZIP. Upload the files inside it to your repository root, including index.html and all .js, .json, image, font, and license files. Keep their filenames intact.
2. In Settings → Pages, deploy from the branch and folder containing index.html.
3. Replace older portfolio files when uploading this update, then refresh the page after deployment completes.

This is a flat, buildless website: every file belongs at the same folder level. No npm install or build is required. Page styles are embedded to preserve the layout, scripts have versioned filenames, and local links work in a repository subdirectory.

The five pages include 28 projects (4 work and 24 academic), topic filters, search, and 25 inline document previews with 325 pages. Project details remain one vertical scrolling view, with page arrows, swiping, keyboard navigation, and accessible page text. Main text is approximately 16–17px; small labels are at least 14px.

The original editable project documents are retained in the private Site source, outside this deployable package. This export contains inline previews without project-file download buttons.

The private Sites deployment has separate access controls. This ZIP does not add authentication to GitHub Pages; choose hosting access that matches your intended audience.
